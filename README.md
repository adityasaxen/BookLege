# BookLege

## 📌 Overview

BookLege is a college student educational resource platform designed
to provide easy access to books, notes and previous-year question papers.

## ✨ Features

- User authentication
- Book search
- Semester and subject filtering
- Book buying/selling
- Notes
- Previous-year question papers
- Admin management

## 🛠️ Tech Stack

- Flutter
- Dart
- Firebase
- Firestore
- Android Studio


## ⚙️ Installation

```bash
git clone https://github.com/adityasaxen/booklege.git
cd booklege
flutter pub get
flutter run
