# BookLege

## 📌 Overview

BookLege is a college student educational resource platform designed
to provide easy access to books, notes and previous-year question papers.

## ✨ Features

- User authentication
- Book search
- Semester and subject filtering
- Book buying/selling
- Notes
- Previous-year question papers
- Admin management

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Flutter | Mobile UI |
| Dart | Application logic |
| Firebase | Backend services |
| Firestore | Data management |
| Firebase Storage | File storage |
| Android Studio | Development |

## ⚙️ Installation

### 1. Clone the repository

git clone YOUR_REPOSITORY_URL

### 2. Open the project

Open the project in Android Studio or VS Code.

### 3. Install dependencies

flutter pub get

### 4. Configure Firebase

Add your Firebase configuration files
and connect the project to your Firebase project.

### 5. Run

flutter run
